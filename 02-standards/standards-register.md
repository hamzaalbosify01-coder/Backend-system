# Standards register

Editions verified against the publishers during the plan review rounds (sources in plan v3.4, sources section).

| Standard | Edition in force | Role in the platform |
|----------|------------------|----------------------|
| ISO 14224 | 2016, 3rd ed. | Equipment hierarchy and failure codes from day one |
| ISO 55000 | 2024, 2nd ed. | Asset management as a management system; the software supports it |
| API STD 53 | 5th ed., Dec 2018 | BOP tests in the compliance register, never the AI loop |
| API RP 7L | 1st ed. 1995, reaffirmed | Inspection and maintenance of drilling equipment |
| API RP 8B | 8th ed. 2014 + Addenda 2019, 2021 | Hoisting tools inspection |
| API RP 4G | 5th ed. 2019 + Add. 2020, reaffirmed 2026 | Mast/derrick inspection categories in HSE |
| IEC 62443 | Series, current | Security for the R3 rig data link, paired with a hardware data diode |
| WITS / WITSML (Energistics) | Current | Rig-to-shore data formats; WITS0 one-way stream suits the diode |
| IADC Drilling Manual | 13th ed., 2025 | Vocabulary and training reference |
| OWASP ASVS | 5.0, level 2 | Application security bar; outside pen test before go-live and yearly |

Legal: Libya Law 6/2022 on cybercrime, Article 78 governs transferring personal data abroad (feeds D5). Full text source in plan v3.4.
